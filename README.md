# SOS Phone — plugin WordPress de devis

Web app de devis réparation (modèle → panne → département → urgence → numéro → prix → RDV).
Shortcode `[sos_phone]`, demandes enregistrées dans « Demandes SOS ».

Les sites où le plugin est installé chargent `assets/` depuis ce dépôt (branche `main`, via jsDelivr) :
toute modification poussée ici arrive sur le site en 2 minutes environ.
